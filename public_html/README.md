# Молодая Гвардия · Щёлково — сайт местного отделения

Сайт волонтёрского отделения: публичная часть, личный кабинет волонтёра,
панель администратора и панель разработчика.

**Технологии:** PHP 8 + MySQL, без фреймворков и Composer — работает на обычном
хостинге SprintHost сразу после загрузки файлов.

---

## Установка

### 1. Создайте базу данных

В панели управления SprintHost: **Базы данных → Создать базу**.
Запишите имя базы, имя пользователя и пароль.

### 2. Загрузите файлы

Загрузите содержимое папки в корень сайта (обычно `public_html` или
`домен.ru/public_html`) — по FTP или через файловый менеджер хостинга.

Проверьте права доступа:

| Папка | Права |
|---|---|
| `config/` | 755 (нужна запись при установке) |
| `uploads/` и вложенные | 755 |
| остальные файлы | 644 |

### 3. Запустите установщик

Откройте в браузере: `https://ваш-домен.ru/install/`

Установщик за два шага:
1. подключается к базе, создаёт таблицы и файл `config/config.php`;
2. создаёт вашу учётную запись с ролью **разработчик**.

### 4. Удалите папку install

После установки **обязательно удалите папку `/install` с сервера.**
Пока она на месте, установщик доступен всем посетителям сайта.

Повторный запуск установщика заблокирован автоматически, если учётная запись
администратора уже создана, но папку всё равно нужно убрать.

### 5. Проверьте настройки

Войдите под своей учётной записью → **Панель разработчика → Состояние системы**.
Там список проверок: версия PHP, HTTPS, режим отладки, права на папки.
Исправьте всё, что отмечено восклицательным знаком.

Затем **Панель разработчика → Настройки сайта**: впишите почту отделения,
адрес, ссылки на ВКонтакте и Telegram.

## Роли и доступ

| Роль | Что доступно |
|---|---|
| **волонтёр** | личный кабинет, запись на мероприятия, рейтинг, свои достижения |
| **администратор** | всё выше + одобрение заявок, волонтёры, мероприятия, новости, начисление очков |
| **разработчик** | всё выше + состояние системы, база данных, настройки, журнал действий |

Роль меняется в **Админ-панель → Волонтёры** (роль «разработчик» может назначить
только другой разработчик).

---

## Как работает приём в движение

1. Человек заполняет анкету на `/register.php`.
2. Учётная запись создаётся со статусом **«на рассмотрении»** — войти нельзя.
3. Администратор видит заявку в **Админ-панель → Заявки на вступление**
   (счётчик новых заявок виден в боковом меню).
4. При одобрении статус меняется на «одобрена», человек может войти.
   При отклонении можно указать причину — она покажется при попытке входа.

Приём заявок можно временно закрыть: настройка `registration_open` = `0`
в панели разработчика.

## Как начисляются очки

- **За мероприятие.** В карточке мероприятия задаётся число очков.
  После проведения администратор открывает **Участники** и ставит отметку
  «участие принято» — очки начисляются автоматически, один раз.
  Если отметку снять, очки и часы возвращаются обратно.
- **Вручную.** **Админ-панель → Начисление очков** — для координации, обучения
  и прочего вне мероприятий. Отрицательное число списывает очки.
- **Уровни** считаются из накопленных очков. Пороги и названия настраиваются
  в панели разработчика (`level_thresholds`, `level_names`).

Вся история начислений хранится в таблице `point_transactions` и видна
волонтёру в его кабинете.

## Что сделано для безопасности

- Пароли хранятся хешированными (`password_hash`), в открытом виде их нет нигде.
- Все запросы к базе — подготовленные выражения, SQL-инъекция невозможна.
- Все формы защищены CSRF-токеном.
- Весь вывод экранируется функцией `e()` — защита от XSS.
- Идентификатор сессии обновляется при входе.
- Папки `config/` и `includes/` закрыты от прямого доступа.
- В `uploads/` отключено выполнение PHP.
- Заблокированная учётная запись выбрасывает из системы при следующем запросе.
- Все значимые действия пишутся в журнал (`audit_log`).

**Перед публикацией проверьте:**
- `debug` в `config/config.php` = `false`;
- сайт работает по HTTPS (бесплатный сертификат Let's Encrypt есть в панели SprintHost);
- папка `/install` удалена.

## Что стоит доделать позже

Проект рабочий, но эти вещи в него намеренно не заложены — их лучше добавлять
под реальные потребности отделения:

- **Письма.** Сейчас об одобрении заявки человека нужно уведомлять вручную.
  Можно добавить отправку через `mail()` или SMTP хостинга.
- **Загрузка изображений** для новостей и мероприятий (поля `cover` в базе уже есть,
  папки `uploads/news` и `uploads/events` подготовлены).
- **Восстановление пароля** по почте.
- **Автоматическая выдача бейджей** — сейчас автоматически выдаётся только
  «Первый шаг», остальные назначаются вручную через базу.
- **Фотогалерея через админку** — сейчас фотографии заданы списком в `gallery.php`.

## Данные, которые нужно заменить

Перед публикацией замените заглушки:

- почта `info@example.ru` → **Панель разработчика → Настройки сайта**;
- ссылки на ВКонтакте и Telegram — там же;
- показатели на главной (волонтёры, мероприятия, часы) считаются автоматически
  из базы; если хотите указать свои цифры — задайте `stat_volunteers`,
  `stat_events`, `stat_hours` в настройках.
