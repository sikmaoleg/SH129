# МГ Щёлково — мобильное приложение (iOS)

React Native / Expo-приложение для волонтёров отделения. Работает поверх
JSON API сайта (`public_html/api/`) через Bearer-токен — тот же аккаунт,
что и на сайте, но отдельная авторизация, не завязанная на браузерную сессию.

## Как запустить на iPhone через ваш MacBook

Xcode не нужен для разработки — приложение показывается в **Expo Go**
(бесплатное приложение из App Store), которое "проигрывает" код живьём.

1. Установите на iPhone приложение **Expo Go** (App Store).
2. На MacBook, в этой папке (`mobile/`):
   ```
   npm install
   npx expo start
   ```
3. В терминале появится QR-код. Отсканируйте его камерой iPhone (или прямо
   из приложения Expo Go) — приложение откроется на телефоне. Любое
   изменение кода на Маке мгновенно подхватывается на телефоне ("live reload").

MacBook и iPhone должны быть в одной Wi-Fi сети.

## Публикация в App Store (когда понадобится)

На данный момент приложение работает только через Expo Go (без учётной
записи Apple Developer). Когда будете готовы публиковаться в App Store:

1. Оформите Apple Developer Program ($99/год) на developer.apple.com.
2. Соберите приложение через EAS Build (`npx eas build --platform ios`) —
   это делает Expo в облаке, локальный Xcode не обязателен даже для этого шага.
3. Отправьте сборку в App Store Connect (`eas submit`).

## Структура проекта

```
src/
  api/          -- клиент к api/*.php сайта (client.ts, endpoints.ts, types.ts)
  context/      -- AuthContext: токен, текущий пользователь, вход/выход
  navigation/   -- вкладки и стеки экранов (React Navigation)
  screens/      -- сами экраны
  components/   -- переиспользуемые UI-элементы (кнопки, карточки и т.п.)
  theme/        -- цвета/отступы -- та же палитра, что и на сайте
  utils/        -- форматирование дат, обёртка для загрузки данных
```

## Что уже готово (Phase 1 -- волонтёрская часть)

Главная, новости (со встроенной галереей и просмотром фото), афиша
мероприятий с записью/отменой, личный кабинет (обзор, мои мероприятия,
рейтинг, достижения, профиль с фото и сменой пароля), вход и регистрация.

Главная/новости/афиша доступны без входа -- как гостю, так и волонтёру;
запись на мероприятие и вкладка "Кабинет" требуют входа.
